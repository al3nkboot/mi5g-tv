# Upstream examples (commit 9071ec8, v2.5.0) that the app does not ship as profiles, because they
# have no curated entry in profile-meta.json (owner decision D2). The profile build skips exactly
# these folders and fails on any other folder without an entry, and ProfilesTest pins this list to
# the submodule, so a new upstream folder can never slip in silently: give it an entry in
# profile-meta.json, or add it here. A TV that matches none of the shipped profiles still gets its
# brand's sure set or the generic plan.
# Every folder up to v2.5.0 was reviewed; the folders below were refused, or parked until a contributor
# confirms the match keys, each with the reason after its name.
byintek-u4    # parked: the header and README give the Skyworth board (RG_HS352_D1E8_SW_B10, HiSilicon Hi3751V350) but no ro.product.model, ro.product.device or brand string, so no key can match this projector; ask the contributor for getprop (model, device, brand, manufacturer). Its home (Zeasn Whale, com.zeasn.whale.saas) is not a known launcher, so a profile would give the clean-up only (Mateus Zanes, PR #414)
philips-55pus7503    # refused: same device, firmware and fingerprint as philips-65pus8102, whose list contains every package of this one; the app resolves one profile per TV, so this list could never be picked (contributed by Iago Veiga, PR #209)
philips-tpm191e    # refused: same board, firmware and fingerprint as philips-75pus8505 (Philips/PH9M_EA_5599/PH9M_EA_5599:12/STT2.230526.001/4215, model TPM191E), so the app could only ever pick one of the two; 75pus8505 is kept because every entry was checked on the TV with dumpsys and its header adds the SOURCES key (org.droidtv.fastip) and USB media keep list; the extra apps this list switches off (Prime Video, Google TV, Play Music, Play Games, TalkBack, DLNA) are owner choices, and DLNA is kept on 75pus8505 because the USB media app binds it (contributed by amadr-95, PR #334)
portronics-beem-470    # refused: the firmware reports the generic Allwinner ADT-3 identity and the header says to match on a build string; the app matches on brand, model, device, SDK and fingerprint, so a profile would either never match or catch every device with that identity; v2.5.0 adds a vendor accessibility helper to the list (upstream #372), which does not change this
redmi-mitv-antl0    # refused: Android 5.1.1 (SDK 22). The launcher needs Android 8 (SDK 26), and this firmware refuses pm disable for the shell, the only way the app switches an app off (the list works with pm hide instead); v2.5.0 adds notes for newer firmware (upstream #403), where the list was not re-tested
