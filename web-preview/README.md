# معاينة الاقتراحات الثمانية

هذه المعاينة التفاعلية لواجهة Mi5G TV بعد تطبيق الاقتراحات. **لا تغيّر تطبيق أندرويد** في هذا المستودع، والفرع `main` بقي كما هو.

الملفات الأساسية:

- `src/components/mi5g/studio.tsx` — الشاشات
- `src/components/mi5g/model.ts` — الأجهزة والخطط والوحدات
- `src/styles.css` — الألوان والخط

ما الذي صار مفعّلاً:

1. لوحة صحة التلفاز وزر تنظيف واحد
2. تايزن و webOS دليل فقط، بلا تنظيف عبر ADB
3. الحذف النهائي خلف كلمة «احذف» ونقطة استعادة، والتجميد هو الافتراضي
4. كتالوج Downloader، والكود الحر تحت «متقدم»
5. وضع المساء: قوائم 0.5× و DNS عائلي، بلا أذان إجباري
6. لكل تلفاز خطته ونقطة استعادته، ونسيان جهاز لا يمسح الباقي
7. فحص منفذ 853 قبل تثبيت DNS
8. فصل «تطبيقاتي» عن «المصنع»، وتطبيقات البث المحمية بلا تعطيل

ملفات `src/routes` و `src/router.tsx` تعتمد على غلاف المعاينة ولا تُبنى داخل مشروع Gradle.
